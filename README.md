# zion-ai-pr-review-swarm
Zion AI PR Review Swarm — multi-agent parallel code review (security, performance, style).

- Live: https://ziontechgroup.com/zion-ai-pr-review-swarm/

## Features
- Parallel specialist agents review security, performance and style simultaneously
- Actionable inline suggestions with severity ranking
- Learns team conventions from past reviews
- Summarized review reports for faster merges
